# The Vibe: which tone fits this README

## Context and Problem Statement

Question category: Vibe.

## Considered Options

- **Technical Clarity** — Direct, fact-dense, low ornament. Tables and code blocks do the talking. The README itself demonstrates the Anti-Slop rules by following them.
- **Organised Chaos** — Playful, opinionated, willing to mock the failure mode. The current README's 'ESLint for prose' and 'treats delve as a syntax error' lean this way.
- **Mixed: chaos hook, clarity body** — Loud opinionated opening that earns attention, then settles into Technical Clarity for the install/use/configure sections. The current README sort of does this; could lean further.

## Decision Outcome

Chose **Technical Clarity**. Direct, fact-dense, low ornament. Tables and code blocks do the talking. The README itself demonstrates the Anti-Slop rules by following them.
